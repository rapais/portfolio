About the Project

An automated fire suppression system built around an ESP32 microcontroller. Flame sensors detect fire events and trigger a servo-controlled suppression mechanism. All events are logged to Firebase for record-keeping, and a Node-RED dashboard provides real-time monitoring and status visibility.

System Components

  • ESP32 microcontroller as the central processing unit
  • Flame sensor array for fire detection
  • Servo actuator for suppression mechanism control
  • Firebase for real-time event logging and data persistence
  • Node-RED dashboard for monitoring and visualization
